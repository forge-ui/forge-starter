# Ask AI 系统功能认知

`lib/agent/system-features.ts` 是页面功能清单，覆盖所有 `APP_MODULE_IDS`，以及个人资料、安全、通知偏好、认证和 Ask AI 自身功能。每项都有真实页面/表单来源。新增模块时 TypeScript 的 `Record<AppModuleId, ...>` 和覆盖测试要求同步补登记。

功能清单与可执行工具分开：前者说明系统实际能做什么，后者由当前用户的读取和操作权限过滤。两条模型链路都固定注入完整的可访问模块摘要，并保留按问题检索的详细知识，避免因检索没命中而回答“没收录”。没有模型时，功能咨询仍可读取本地清单。

| 范围 | 系统认知 | 助手执行边界 |
|---|---|---|
| 工作台 | 指标、图表、最近账号；真实数据与演示曲线区别 | 导航；实时账号数据用原查询工具 |
| 业务账号 | 查询、筛选、详情、新建、修改、删除、导出 | 保留既有草稿确认、页面保存、成功回执和续办 |
| 角色 | 列表、详情、创建、编辑、删除、权限分配及编码规则 | 查询、真实详情；创建/修改/删除草稿确认后进入原页面表单或删除确认，保存成功后读回；授权只准备用户明确指定的权限 |
| 菜单 | 目录、父子级、路径、排序、状态、CRUD及侧栏可见条件 | 查询、详情、创建/修改/删除草稿与页面保存回执；内置菜单保护；目录不等于侧栏登记 |
| 权限 | 资源、操作、编码、CRUD及角色关联 | 查询、详情、创建/修改/删除草稿与页面保存回执；授权在角色页面核对 |
| 模型 | 供应商、接入、编辑、删除、默认、启停和连接测试 | 查询/筛选/详情、创建/修改/删除、启停/默认草稿；明确请求且确认后由页面测试连接；Key仅页面输入 |
| 应用 | 类型、菜单模块、首页、链接、打开方式、应用切换及CRUD | 读取当前浏览器上报的列表；创建/修改/删除草稿带入原页面；回执标注browser-local/browserReported，不宣称服务端独立核实 |
| 个人/认证 | 资料、改密、通知偏好、登录注册、SMTP找回/重置 | 直接打开本人资料/改密/通知设置原弹窗；说明认证流程，不收集密码或重置令牌 |
| Ask AI | 会话、全屏、模型、快捷卡片、文本附件和已授权工具 | 保留原有能力；不承诺未实现功能 |

`lib/agent/resource-tools.ts` 和 `app-tools.ts` 负责准备草稿；`page-entry-tools.ts` 保留详情等页面入口。操作由当前用户的模块读取权限与动作权限共同过滤；应用配置统一遵循现有 `settings:update`。个人设置工具仅打开本人原弹窗，不填写或代存。

写入链路：助手提出签名确认单 → 确认时再次校验权限和页面上下文 → 页面验证目标及版本 → 原页面表单保存/删除确认 → 数据与操作回执同一事务提交 → 服务端读回 → 同一会话继续原请求。重复请求返回同一回执；过期目标、取消单和不同内容重试拒绝。角色授权及模型默认切换也在原事务中执行。连接检测使用lastProbeAt，不修改模型配置updatedAt，避免后台检测让编辑草稿失效。

本地应用配置与服务器操作记录无法跨localStorage和PostgreSQL做原子提交：先保存本地，再上报结果；上报失败明确提示重试，不伪称已核实。服务端记录只证明收到当前用户的浏览器报告，状态保持committed，不能升级为verified。当前产品不能删除，过期本地快照拒绝执行。

## 环境与验证

- 页面办理要求 `SEMANTIC_ENABLED=true`，以及已配置PostgreSQL、执行项目数据库初始化。开关关闭时保留原人工页面操作，助手不会绕过开关写库。部署环境的开关与数据库尚未代为验证。
- `pnpm check`通过；保留范围外/ref的15条历史颜色警告。
- 隔离数据库与实际HTTP服务器：semantic/harness/navigation测试178项全部通过，零跳过。包括四种资源签名确认、页面修改字段后保存、重复提交、过期修改、事务回滚、取消与权限过滤，以及本地应用来源标记。测试的模型网络回应用桩，不代表所有供应商连通性。
- Chrome真实模型：角色草稿确认、原表单预填、保存、详情和同一会话查询核对全部跑通；测试角色未分配任何权限，验证后已按精确ID清理。
- Chrome真实模型：应用草稿预填名称/类型/网址/新标签页，取消未保存；通知偏好请求直接打开现有系统设置弹窗，取消未修改。
- Chrome页面审查：菜单/权限/模型列表与表单、应用列表、个人设置；截图在 `tmp/ask-ai-panel/`。菜单/权限/模型的新写入全流程通过真实HTTP与隔离数据库验证，未逐一通过真实模型点击保存。
- 分模块规范审计见 `docs/audits/2026-10-16-ask-ai-workflow-*.md`。技术验证不替代用户体验验收。本次没有提交、推送、发布或修改core。
