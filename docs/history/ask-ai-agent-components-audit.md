- 浏览器真实模型：ApprovalCard 多选回传账号、角色；Checklist / ChecklistItem 勾选确认后提交已完成/未完成项；RecommendationCard 替代建议生成查询；InsightCards 从 1/2 切到 2/2；CommandSearch 过滤客服并发送完整问题；ContextCards 展示来源摘要。
- AgentDiffTable 点击排除一行后只提交剩余行；AgentCodeBlock 从 Code 切到 Diff。ToolChips 显示待核对差异数量；任务内使用真实事件与状态。
- Qwen 多选账号、角色后，同一任务成功生成对应清单与流程图；流程节点可选择。刷新恢复历史后，清单原勾选仍保留。展开处理记录核对任务状态及工具详情，结束时收起记录并恢复原 sub2api 模型选择。
