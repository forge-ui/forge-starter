## 选型

| 场景 | 选 |
|---|---|
| 后台列表（订单 / 客户 / 商品） | `DataTable` 6-8 列 |
| 全宽铺满页 | `FullWidthTable` |
| 行内编辑菜单 | 最后一列放 `CellKebabMenu` |
| 状态列 | `StatusBadge` 或 `CellStatusDot` |
| 进度列 | `CellProgressValue` / `CellProgressBar` |
| 操作列 | `CellActions` / `CellKebabMenu` / `CellLink` |
| 文件列 | `CellFile` |
